# AI 协同开发工作流

本项目在开发过程中引入 AI 编程助手（WorkBuddy）作为协同开发者，涵盖代码生成、Bug 修复、文档编写、美术资源生成与构建优化等多个环节。以下是主要 AI 协同流程，供求职展示参考。

## 1. 代码生成与架构实现

- 分层架构（框架层 / 玩法层 / 关卡层 / 表现层 / 工具层）由 AI 按设计文档生成骨架代码，人工复核后落地。
- 玩家控制器、状态机、事件中心、对象池、存档系统等核心模块由 AI 生成初版，随后经过人工调参与测试验证。
- 所有新增代码在提交前通过编译验证与 EditMode 测试。

## 2. Bug 修复与回归

- 关卡目标链死锁、钥匙门翻滚穿透、净化剂统计夹取、UI 面板排序等问题，由 AI 定位根因并给出修复补丁。
- 修复后通过 Unity MCP 执行代码进行运行时验证，确认无误后再提交。

## 3. 美术资源生成

- 使用 ComfyUI（SDXL 1.0）结合 isnet-anime 抠图管线，逐帧生成 2D 动画素材。
- 资产管线包含：逐帧独立生成 → 抠图透明底 → 拼版网格 → 像素级后处理（连通域清理、尺度归一、基线对齐）。
- 所有生成的贴图落入 `Assets/Art/`，再在 Unity 中刷新确认。

## 4. 构建优化

- 定位并修复 Unity 纹理格式回退缺陷：非 4 倍数画布触发 RGBA32 未压缩存储，导致构建体积从 1.6 GB 膨胀。
- 将入包纹理导入上限统一下调至 512 像素，构建体积降至 333 MB，画面质量无损。

## 5. 文档编写

- 开题报告、技术设计文档、关卡设计文档、需求规范等由 AI 按模板生成初稿，人工校对核对数据一致性。
- 需求与实现通过 `requirements.md`（EARS 格式）逐条对照，确保每条功能都有可核查的验证方式。

## 协作原则

- **人类主导决策**：所有主观资产（美术风格、文案、手感数值、玩法规则）由人类拍板，AI 仅负责执行与建议。
- **可复现验证**：AI 生成的结论必须附带实测证据（构建日志、性能报告、测试用例），不可凭记忆宣称完成。
- **版本控制**：所有改动通过 Git 提交并推送到 GitHub，保留完整提交历史。
