# AI 协作说明

StarEco 是使用 AI 编程助手辅助开发的 Unity 2D 项目。现有项目记录涉及 WorkBuddy、Codex、Unity MCP，以及不同阶段使用的图像生成与处理工具。仓库不把 AI 辅助产物描述为全部手写，也不对无法从记录核实的人工参与比例作量化承诺。

## 协作方式

- 玩法、美术风格、关卡表现与验收目标由项目负责人决策；AI 协助拆解任务、实现代码和定位问题。
- 代码、场景与资产通过 Git 保存；开发文档记录设计目标、变更与已知问题。
- Unity MCP 用于查询编辑器、场景及控制台，执行测试与构建。
- 美术曾使用图像生成服务和本地 ComfyUI；处理链包括抠图、网格拼版、帧尺度归一与基线对齐。原始资料见 `Assets/Art/README_素材说明.md` 和 `Tools/art-pipeline/`。

## 本次发布的可核查证据

2026-11-03 运行现有 EditMode 测试，13 项通过；Windows x64 / Mono 构建成功；检查了标题及第一关画面和启动日志。具体提交、构建体积、警告与测试局限见 [发布验证记录](Release-2026-11-03.md)。

这些结果只覆盖本次记录的验证范围，不表示每个历史提交都已测试，也不表示三关完整通关或性能指标已经在本轮复测。

## 面试讲解入口

可选择玩家状态机、事件驱动目标链、ScriptableObject 配置或美术处理管线，结合代码说明：问题是什么、为什么这样设计、AI 做了哪些辅助、如何验证、还存在哪些限制。

展示时区分实际实现、设计规划和未启用功能；没有实测证据的数据不作为性能承诺。
