## 4. 美术基准（★ 血泪教训，接手者必读）

### 4.1 pivot 必须是 Center
- **501 张精灵的 `.meta` 一律 `alignment: 0` + `spritePivot {x:0.5, y:0.5}`**
- `TextureImporter.SpriteAlignment` 枚举真实值：`0=Center, 1=TopLeft, 2=Top, 3=TopRight, 4=Left, 5=Center, 6=Right, 7=BottomLeft, 8=Bottom, 9=BottomRight`
  → **`1` 是 TopLeft，不是 BottomCenter**。历史上 AI 把 1 当成 BottomCenter 批量写入，导致全项目碰撞体与视觉整体偏移 (0.92, -2.15)（视觉陷地、碰撞体浮空），修复代价极大。
- 本工程 `TextureImporter` **不暴露** `spriteAlignment` / `spriteMeshType`，改 pivot 的唯一可靠途径是**直接编辑 `.meta` 文本层**。
- 永久规则：**改 pivot 前必须运行时实测确认**（读 `sprite.bounds.center`），批量改完立即抽验若干张。

### 4.2 碰撞体统一约定
```csharp
// Sprite Pivot = Center → sprite.bounds 中心即 transform 原点
BoxCollider2D.size   = sprite.bounds.size * 0.9f;
BoxCollider2D.offset = Vector2.zero;
```

### 4.3 命中盒 / 发射点约定
```csharp
// 沿 +X 前伸到碰撞体右缘外一点，y = 0（Center pivot 下即身体中心）
float x = collider.size.x * 0.5f + 0.1f;   // 简易敌人
float x = collider.size.x * 0.44f;           // Boss（系数按体积调）
hitbox.localPosition = new Vector3(x, 0f, 0f);
```
同步：`EnemyAttackHitbox._localOffset` 是 private字段，靠反射写入，编辑器脚本与运行时赋值必须一致。

### 4.4 localScale 语义
碰撞体 `size` 是**局部单位**，会被 `transform.localScale` 放大。Boss 的 `localScale = 2.2` 是**体量设计意图**，不要"修正"它。
反之：若物体靠大 `localScale` 撑世界尺寸（如Level02 的 `RaftPath.localScale = 112.5`），则 `localSize` 要写成 `worldSize / lossyScale`（如 `0.039`），直接写世界值会放大 112 倍。

### 4.5 PPU 与横版地面
- 角色/敌人/Boss 贴图 PPU ≈ **378**（世界高度约 2 单位）
- 地面瓦片 PPU ≈ **32**（瓦片高 4 世界单位）
- 俯视(top-down)纹理不能直接当横版地面用。`.workbuddy/to_side_view_tiles.py` 是转换脚本（横向 wrap 无缝 → 取上缘作表层带 → 土体取上 1/3 逐行均值 + 高斯模糊 → 向下压暗去饱和 → 顶部高光描边 → 上下 wrap），产物 512×128

### 4.6 命名规范（社区规范，用户选定）
- clip / 状态名：**PascalCase 无前缀** —— `Idle / Run / Jump / Fall / Land / Hurt / Death / Attack / Interact`
- 美术帧目录：保留 `Player_` 前缀

## 9. 环境坑位（Unity MCP 相关）

- **MCP 桥会被同机其他 Unity 工程抢占**。若 `execute_code` 的cwd 不对，用报错里的 `Available instances` + `set_active_instance` 切回；必要时关掉占用工程（本项目曾遇到 `zeldaLike` 抢占，PID 76112）。
- Unity Editor 启动需突破沙箱：`"E:\software\Unity Editor\2022.3.62f3c1\Editor\Unity.exe" -projectPath "E:\desktop\UnityXiangMu\BiShe\BiShe"`
- 新 PNG 用 `AssetDatabase.ImportAsset` 后 `LoadAssetAtPath<Sprite>` 仍可能为 NULL → 改用**覆盖同名原文件**（保GUID），再 `refresh`
- `FrameTimingManager.GetLatestTimings` 在 Editor 空闲时返回恒定值，性能取样必须"场景加载完主动读单帧"
- `execute_code` 常见编译坑：
  - `Transform.activeSelf` 不存在 → `gameObject.activeSelf`
  - `Collider2D.size` 不存在 → 先转 `BoxCollider2D`
  - `Object` 二义 → 全写 `UnityEngine.Object`
  - `FindObjectsByType` 需 2 个参数（或用旧版 `FindObjectsOfType`）
  - `FrameTiming[].cpuFrameTime` 是 `double`
  - `Physics2D.SyncTransforms()` 返回 void，不能赋值
  - `ImportAssetOptions.ForceSynchronizedImport` 不存在
