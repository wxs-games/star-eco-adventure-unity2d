# 美术资源批量生成流程（用一次读一次）

> **给 AI 的说明**：当用户要求"批量生成/补齐美术资源"时，先完整读一遍本文件，按流程执行；平时对话不需要读本文件。
> **给用户的说明**：以后新开批次资源，直接对 AI 说这句话即可——
> 「读 Assets/Art/美术资源生成流程.md，按排期表'未开始'条目继续生成，风格按 README 基准，完成后回写排期表并输出对齐报告」

## 一、三份核心文件的分工

| 文件 | 角色 | 何时用 |
|---|---|---|
| `2D游戏动画资源排期表.xlsx` | **生成工单**：Clip 名、帧数、Samples、循环、事件帧、制作状态 | 规划期填条目；执行期 AI 按"未开始"条目干活、完成后回写"已完成" |
| `README_素材说明.md` | **风格基准**：画风、各角色 cell/身高/localScale、Unity 导入设置 | 生成与处理素材时全程对照，保证新素材与旧素材风格统一 |
| 本文件 | **操作手册**：流程步骤、脚本用法、复用指令 | 每批次开工时读一次 |

## 二、标准流程（6 步）

1. **测基准**：用脚本测量既有精灵表（cell 尺寸、条内身高中位数、底留白、水平居中），得到量化基准。已有基准速查见下方"基准速查"。
2. **生成 raw**：按排期表条目逐条生成白底网格精灵表（prompt 要素见"四"），存到 `Art\Art\<角色>\Sheets\raw\<名>_raw.png`。
3. **处理落盘**：跑 `process_sheets.py` → 自动切格 → 白底连通域抠像（保留白衣/眼白）→ 按条内身高中位数统一缩放 → 脚底基线对齐（底留白 7px）→ 重拼等大透明精灵表，同时输出 `Sheets\<名>_sheet.png` + `Frames\<名>\<名>_NN.png`。
4. **目检**：Read 每张成品 sheet，检查抠像干净、帧朝向统一朝右、动作姿态正确；不合格的重生成（如朝向单一帧错，可直接翻转变换修复，不必重新生成）。
5. **回写排期表**：状态改"已完成"、画布尺寸改真实 cell、精灵表路径核对；`README_素材说明.md` 同步新增动作行与帧数合计。
6. **验证 + 报告**：Unity 刷新资产、控制台 0 error；按 AGENTS.md 协议输出需求对齐报告。

## 四、生成 prompt 要素（SDXL 口径）

- 开头声明用途与网格：`[Game sprite sheet, CxR grid, N frames on pure white background]`
- 逐帧动作分解（(1)…(N)），保证帧序列可读
- 角色特征全部列出（帽子/马甲/背包/机械爪等），句尾加 `consistent character design across all frames`
- 统一朝右 `always facing right`；机械单位加 `painterly cel shading, weathered rusty metal`
- 结尾：`no text, no grid lines, pure white background, each frame fully contained in its cell`
- 尺寸限制：总像素 ≥ 3,686,400（如 2560×2560、3456×2304）；输出可能是 .jpg，处理脚本自动转 .png

## 五、处理脚本（位于 `<工作区>\.workbuddy\scripts\`）

| 脚本 | 用途 |
|---|---|
| `measure_base.py` | 测量既有精灵表基准（cell、身高、留白） |
| `process_sheets.py` | 核心：切格→抠像→统一缩放→基线对齐→重拼，落盘 Frames+Sheets；SPECS 表内新增条目需写 name/cols/rows/n/cell/target_h |
| `fix_victory.py` | 单帧水平翻转修复朝向的示例（可复制改路径复用） |
| `update_schedule.py` | 批量回写排期表状态/尺寸/路径 |
| `make_preview.py` | 拼 17 条新动作总览预览图（深绿底，存 `_预览\`） |

> 注意：`.workbuddy\scripts` 是会话工作目录，**换机器或清理后脚本会丢**；新项目复用时把这几个脚本拷进新项目旁的固定目录。

## 六、新项目复用清单

1. 复制本文件 + `README_素材说明.md` 到新项目 `Assets\Art\`
2. 复制排期表 xlsx，**清空两张清单条目、保留表头/公式/资源规范 sheet**，按新项目角色重填
3. 拷贝第五节脚本目录
4. 对 AI 说本文件开头那句复用指令
